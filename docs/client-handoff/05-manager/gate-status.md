# 客户端合同与联调 Gate

生成本交接包只表示任务材料 ready，不改变端侧实现 Gate：

```text
CLIENT_CONTRACT_BASELINE_GATE=YES
ANDROID_CONTRACT_BINDING_GATE=YES
WEB_CONTRACT_BINDING_GATE=YES
IOS_CONTRACT_BINDING_GATE=NO

ANDROID_FOUNDATION_LOCAL_GATE=YES
IOS_FOUNDATION_LOCAL_GATE=NO
WEB_FOUNDATION_LOCAL_GATE=NO

STAGING_CONSTRUCTION_APPROVED=YES
PRIVATE_PRE_STAGING_EXECUTION_PLAN_READY=YES
PRIVATE_PRE_STAGING_EXECUTION_READINESS=NO
STAGING_RUNTIME_READINESS=NO
CLIENT_INTEGRATION_STARTED=NO
THREE_CLIENT_DEFINITION_OF_DONE=NO

EXPORT_BUSINESS_GATE=NO
FULL_PRODUCTION_GATE=NO
```

辅助状态：

```text
ANDROID_HANDOFF_READY=YES
IOS_HANDOFF_READY=YES
WEB_HANDOFF_READY=YES
IOS_PROJECT_PRESENT=NO
IOS_PROJECT_IMPORT_REQUIRED=YES
WEB_REFRESH_COOKIE_STATUS=ACCEPTED_WITH_STAGING_VALIDATION
```

`CLIENT_CONTRACT_BASELINE_GATE=YES` 只表示 Android 与 Web 已精确绑定同一份 `1.5.0-contract` 快照、hash 和生成模型输入。`ANDROID_FOUNDATION_LOCAL_GATE=YES` 只表示 Android 本地 `/api/v1` transport 与构建门禁已建立；二者都不表示 Staging 已部署或联调已经开始。

`PRIVATE_PRE_STAGING_EXECUTION_PLAN_READY=YES` 只表示目标、命令、影响、验证和回退方案已落盘。由于服务器写入、`sudo`、SMTP、staging seed/reset、私有 Android HTTPS 路由仍需单独批准或补齐，执行 readiness 继续为 `NO`。

`*_HANDOFF_READY=YES` 只表示任务书、合同、提示词和验收清单已可分发，不表示跨端业务闭环完成。
